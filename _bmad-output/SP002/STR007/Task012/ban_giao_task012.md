File chính: `spikes/pglite-scale/measure.mjs`, `spikes/pglite-scale/page.html`, `spikes/pglite-scale/package.json`, `spikes/pglite-scale/results.json` (số thô lần chạy 2), `_bmad-output/SP002/STR007/Task012/ket_qua.md`.

Chưa chạy lại `npm run measure` sau bản sửa cuối (chỉ `node --check`) và chưa chạy `npm ci` từ thư mục sạch.

Còn lại: số lần chạy 1 không có file thô, chỉ có bảng in ra; tiến trình thoát ngay sau bảng chưa kiểm.
Chưa làm được: đo Chrome headed, Safari, Firefox, điện thoại, máy RAM thấp; đo trên Vercel qua mạng thật.
