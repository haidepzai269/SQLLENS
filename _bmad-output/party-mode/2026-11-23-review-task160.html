Phần ba

Bảy phát hiện, kèm bằng chứng

L1 — Mất khoá ngoại vĩnh viễn, test vẫn xanhNghiêm trọng

Sáu helper dọn database trong test xoá cloud_projects bằng CASCADE mà không liệt kê hai bảng con. CASCADE xoá khoá ngoại, để nguyên bảng; lần Migrate sau gặp CREATE TABLE IF NOT EXISTS nên bỏ qua. Khoá ngoại không bao giờ được dựng lại. Đo: fk 1 → 0, rồi DELETE FROM cloud_projects để lại token_mo_coi = 1.

Sửa: thêm room_invite_tokens, room_baton vào đầu cả sáu danh sách DROP, cộng hai câu DROP cứng.

L2 — 006 hỏng trên schema đã thoái hoáNghiêm trọng

Sau L1, chạy thẳng file 006 báo ERROR: relation "public.cloud_project_members" does not exist (exit 3), vì policy room_baton_select đọc bảng đã bị helper cũ xoá. Không manh mối nào nói schema đang thiếu bảng nền.

Sửa: khối kiểm điều kiện tiên quyết, RAISE EXCEPTION nêu tên bảng thiếu.

L3 — Khối tự kiểm không kiểm cộtTrung bình

Bảng dở dang (token, project_id) vẫn exit 0 và in thông báo thành công. Trong khi TestCloudPreexistingPartialTable chứng minh 003 từ chối bảng dở dang. 006 không có gì tương đương.

Sửa: kiểm tập cột của cả hai bảng, lệch thì RAISE EXCEPTION.

L4 — used_at là cột chếtTrung bình

Không policy UPDATE, nên không role nào ghi được. Test còn khẳng định UPDATE ảnh hưởng 0 hàng.

Sửa: xoá cột khỏi 006, xoá luôn assertion khẳng định nó là cột chết.

L5 — Vé mời lưu dạng thôTrung bình

token TEXT PRIMARY KEY giữ nguyên bí mật của link mời, trái khuôn sessions.token_hash bytea ở 001_init.sql:18-20. Task161 định lưu sha256 vào cột tên token kiểu TEXT — cột nói dối về nội dung.

Sửa: token_hash BYTEA PRIMARY KEY CHECK (octet_length(token_hash) = 32). 006 chưa chạy ở production nên đổi bây giờ miễn phí.

L6 — room_baton.holder_id không có indexThấp

Khoá ngoại holder_id → users(id) ON DELETE SET NULL không có index, nên xoá một user buộc PostgreSQL quét toàn bảng room_baton. Đo: 0 index khớp.

Sửa: thêm room_baton_holder_id_idx.

L7 — Tài liệu nói sai về gitThấp

Bốn file trạng thái còn ghi Task160 “chưa review độc lập, chưa merge” trong khi main đã có 84083ef. Đây là lần thứ hai trong SP024 tài liệu lệch git — lần đầu là DE_XUAT_STORY_SP024 có trên main nhưng thiếu trong worktree, sửa ở 663cb16.

Sửa: cập nhật SP024/README.md, STR113, STR114, STR116, cộng biên bản phòng. Commit e375517 và 493b579.
