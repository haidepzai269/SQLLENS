# Bàn giao Task040

Đã làm: component `BTreeView` tự vẽ cây B-Tree bằng SVG (không viewBox, chữ 12,5 px), nền tối. Tầng root, internal, leaf, cạnh nối con, cạnh `next` giữa các leaf, đường đi tô màu đèn, khối `+N node` theo `hidden`, nhãn kết luận đúng nhãn truyền vào, bản tóm tắt cho trình đọc màn hình. Hai kiểu "Cố định" (mặc định) và "Kéo tự do" (chuột, cảm ứng, phím mũi tên, kéo nền để cuộn, nút "Xếp lại"); thả xong node được đẩy ra để cách nhau tối thiểu 8 px (thực tế 10 px vì viền 1,5 px). Chạy đúng khi không có `path`, khi `path` trỏ trang bị ẩn, cây một node, localStorage bị chặn.
File chính: `web/src/modules/btree-reader/view/btree-view.tsx` (xuất `BTreeView`, `nodePosition`, `readStoredMode`), `layout.ts` (bố cục, `settle`), `fixtures.ts`, `layout.test.ts`; `web/messages/{vi,en}/btree.json`; route thử `web/src/app/[locale]/e2e-btree/`; `web/e2e/btree-view.spec.ts`; ảnh 390 px và 1440 px, vi và en, trong thư mục task.
Kết quả kiểm tra (máy đang bận, cổng 3140, --workers=1): `npm run check` thoát 0 (196 test trước khi thêm; sau thêm ca layout vẫn thoát 0); `API_ORIGIN=http://localhost:8080 npm run build` thoát 0; `npx playwright test e2e/btree-view.spec.ts --workers=1` 15/15 đạt; toàn bộ `npx playwright test --workers=1` ở lần chạy trước khi sửa theo review: 84 đạt.
