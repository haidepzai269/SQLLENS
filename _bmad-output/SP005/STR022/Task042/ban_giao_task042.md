## Hướng dẫn cho chủ dự án thử AC7 và AC7b

1. Google Cloud Console: tạo OAuth client kiểu Web, Authorized redirect URI `http://localhost:3000/api/auth/google/callback`. GitHub: OAuth App, Authorization callback URL `http://localhost:3000/api/auth/github/callback`. (Khi lên Vercel thêm URI `https://sqllens-bice.vercel.app/api/auth/<provider>/callback`.)
2. `cp api/.env.example api/.env` rồi điền: `DATABASE_URL` (Neon, không qua pooler), `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`, hai cặp client id/secret, `PUBLIC_ORIGIN=http://localhost:3000`.
3. Terminal 1 (bash): `cd api && set -a && . ./.env && set +a && go run ./cmd/server` (PowerShell: nạp từng biến vào `$env:` rồi chạy `go run ./cmd/server`). Gin nghe cổng 8080; migration tự chạy.
4. Terminal 2: `cd web && npm run dev` (rewrites chuyển `/api/*` tới `http://localhost:8080`; kiểm `apiOrigin()` trong `web/next.config.ts` nếu cần đặt biến).
5. AC7: mở `http://localhost:3000/api/auth/google/start?next=/vi/lab`, đồng ý, phải về `/vi/lab` có cookie `sid`; mở `http://localhost:3000/api/me` thấy `{id,name,avatarUrl,provider}`. Lặp với `github`. Thử bấm Hủy ở trang đồng ý: về trang đích với `?auth_error=cancelled`.
6. AC7b: trong DevTools Console của trang `localhost:3000` chạy `fetch('/api/mysql/ping',{method:'POST'}).then(r=>r.status)`, kỳ vọng 204 (Origin do trình duyệt tự gửi). Lặp vài lần rồi vào Upstash Console > Data Browser, thấy khóa `quota:<hash>` có giá trị tăng và TTL khoảng 24 giờ. Nếu luôn trả 503 `quota_unavailable` (log Gin ghi `quota: rule=mysql_session unavailable`) thì Upstash thật từ chối `EVAL`, phải sửa `api/internal/quota/quota.go`.
7. Đánh dấu AC7 và AC7b đạt chỉ sau khi chạy xong các bước trên.
